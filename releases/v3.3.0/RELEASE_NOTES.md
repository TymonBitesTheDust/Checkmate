# Checkmate 3.3.0

| | Download | Runs on |
|---|---|---|
| 🪟 Windows | `Checkmate.exe` | Windows 10 and 11 (64-bit) |
| 🤖 Android | `Checkmate.apk` | Android 7.0 and newer. Installs over 3.1.3 (same signing key), so nothing is lost |
| 🌐 Browser | `Checkmate.html` | Any modern browser, also offline |

The Chrome/Edge extension isn't in this release; 3.1.3's `Checkmate-extension.zip` still works.

## What's new in 3.3.0

- **Settings → Add-ons.** Features for particular needs, each with its own switch, so they stay out of the way for everyone else. Monash is the first one (it used to be its own Settings tab), and more will follow. If your Monash links are already connected, it's on for you.
- **A timeline on Today.** A line across the day with a dot for each task and event that has a time, bars for how long events run, and a marker for now. Hover over a dot to see what it is; click it to see everything at that time. Turn it on with the eye button on Today, or in Settings → General.
- **Show or hide the Done and Left cards** on Today with the same eye button, or in Settings → General.
- **Change any keyboard shortcut**, like a game's controls: in Settings → Shortcuts, click a key and press the new one. If two keys clash, they swap, and button tips show the keys you chose.
- **Tide** no longer shows the button guide in the bottom-right corner.

## Also in this release: Monash (from 3.2.0 and 3.2.1)

3.2.0 and 3.2.1 weren't published here, so this is the first download with them.

- **Connect Monash** (now Settings → Add-ons → Monash University): paste your private calendar links from Moodle and Allocate+, and your classes and deadlines show on the calendar in separate parts: Lectures, Tutorials & labs, Homework, Quizzes and Exams. Show or hide each part. Checkmate never asks for your Monash password. The Windows and Android apps read these links (a browser page can't); add them on any device and everything syncs.
- **A Monash project** lists everything to do, with each assignment, quiz and exam as a task in date order. Tick one off in the project or from its card on the calendar, and it stays ticked when Moodle is read again. If Moodle moves a deadline, the task moves too.
- If something lands in the wrong part, choose the right one on its card, and Checkmate remembers.
- Exams from Allocate+ go in Exams, named like "FIT1045 Exam", and a coming exam becomes a task in the Monash project.
- Seminars go in Lectures, classes have short names like "FIT1045 Studio", and "Open in Maps" finds the building. Moving a class to another part moves every week of it.

## 3.3.0 更新內容

- **「設定 → 附加功能」**：為特定需要而設的功能，每個都有自己的開關，不需要的人就不會看到。第一個是 Monash（以前是「設定」中的獨立分頁），之後會加入更多。如果你已連接 Monash 連結，它會自動開啟。
- **「今天」的時間軸**：以一條橫線顯示當天，每項有時間的任務和活動都是一個圓點，活動的長度以橫條表示，並標示現在的時間。把滑鼠移到圓點上可查看是甚麼；點一下即可查看那個時間的所有安排。可以用「今天」的眼睛按鈕或在「設定 → 一般」中開啟。
- 可以用同一個眼睛按鈕或在「設定 → 一般」中，**顯示或隱藏「今天」的「完成」和「剩餘」卡片**。
- 可以像遊戲的操控設定一樣**更改任何快捷鍵**：在「設定 → 快捷鍵」按一下按鍵，再按下新的按鍵。如果兩個按鍵衝突，它們會互相對調，按鈕提示也會顯示你選擇的按鍵。
- **Tide** 不再在右下角顯示按鍵提示。

## 同時包含：Monash（來自 3.2.0 和 3.2.1）

3.2.0 和 3.2.1 沒有在這裡發布，所以這是第一個包含它們的下載版本。

- **連接 Monash**（現位於「設定 → 附加功能 → Monash 大學」）：貼上 Moodle 和 Allocate+ 的私人日曆連結，課堂和截止日期就會分類顯示在日曆上：講課、導修與實驗、功課、小測和考試。每個類別都可以顯示或隱藏。Checkmate 絕不會要求你的 Monash 密碼。
- **Monash 專案**會按日期列出所有待辦事項，每份功課、小測和考試都是一項任務。在專案或日曆卡片上剔除後，再次讀取 Moodle 時仍會保持完成。如果 Moodle 更改截止日期，任務也會跟著更改。
- 如果項目分錯類別，可在卡片上選擇正確的類別，Checkmate 會記住。
- Allocate+ 的考試會歸入「考試」，名稱也會清楚標明，即將舉行的考試也會成為 Monash 專案中的任務。
- 研討課歸入「講課」，課堂名稱也簡短了，「在地圖中開啟」也能找到大樓。把課堂移到其他類別時，每週的同一課堂都會一起移動。
